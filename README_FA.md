# عضو بگیر — نسخه اولیه اندروید

این پروژه یک نمونه اولیه Kivy با رابط فارسی و تم سبز روشن/سفید است.

## امکانات فعلی
- ورود آزمایشی با شماره موبایل و کد ثابت `123456`
- تشخیص مدیر بر اساس شماره تنظیم‌شده در `app.py`
- ساخت سفارش توسط مدیر
- نمایش سفارش‌های فعال
- ثبت درخواست انجام سفارش (بدون بررسی واقعی عضویت روبیکا)
- کیف پول و ثبت تراکنش
- افزایش/کاهش سکه کاربر از پنل مدیریت
- نمایش کاربران و سفارش‌ها

## نکات مهم قبل از استفاده واقعی
1. این نسخه پیامک واقعی ارسال نمی‌کند. کد `123456` فقط برای آزمایش رابط کاربری است.
2. شماره مدیر در فایل APK قابل استخراج است؛ این روش برای امنیت واقعی مناسب نیست. در نسخه عملیاتی باید نقش مدیر در سرور و پس از احراز هویت امن تعیین شود.
3. اتصال به روبیکا و بررسی عضویت واقعی پیاده‌سازی نشده است. باید از API رسمی/مجاز و مستندات معتبر استفاده شود.
4. پرداخت آنلاین، انتقال واقعی سکه بین حساب‌ها، دعوت با لینک یکتا، گردونه تصادفی و پشتیبانی آنلاین هنوز به سرویس سمت سرور نیاز دارند.
5. دیتابیس SQLite در این نسخه روی همان دستگاه ذخیره می‌شود؛ کاربران چند دستگاه با هم همگام نمی‌شوند.

## اجرای آزمایشی روی کامپیوتر لینوکس
```bash
pip install kivy arabic-reshaper python-bidi
python app.py
```

## ساخت APK
ساخت APK با Buildozer معمولاً روی Linux انجام می‌شود. برای ساخت از گوشی می‌توان از محیط ابری Linux مانند GitHub Actions استفاده کرد.
```bash
pip install buildozer
buildozer android debug
```
خروجی معمولاً در پوشه `bin/` ساخته می‌شود.

## ساخت با GitHub Actions
فایل workflow را می‌توان در مرحله بعد اضافه کرد. برای اولین بار بهتر است ابتدا اجرای محلی/ابری و وابستگی‌های Kivy بررسی شود.
